# Feature Ideas

## Community Library

- [ ] Clicking a book card opens a detail view (similar layout to the add book modal) showing full info
- [ ] Ability to add/edit tags on existing books
- [ ] More friction before deleting a book (e.g. type to confirm, or require password)
- [ ] Find a physical book scanning app to bulk import data — add book form is a stopgap until the library is populated
- [ ] Filter dropdown: existing filter values should display as grey tiles (matching the tag selector style in the add book modal)
